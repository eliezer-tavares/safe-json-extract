# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a Vulnerability

If you discover a security issue, please open a private report through GitHub Security Advisories or contact the maintainer directly.

Please include:

* Steps to reproduce
* Impact assessment
* Suggested mitigation if available

All reports will be reviewed as quickly as possible.

# safe-json-extract

## Architecture Specification v1.0

Author: Eliezer Tavares de Oliveira

---

# Vision

safe-json-extract is a tiny, dependency-free JavaScript library designed to safely extract, validate, normalize and repair JSON data coming from unreliable text sources.

The primary use case is Artificial Intelligence output, but the library is intentionally provider-agnostic.

The goal is simple:

Transform unpredictable text into reliable data.

# Public API

Users should only need:

const {
extractJson,
extractArray,
safeParse,
repairJson,
isJson,
extractCodeBlock,
normalizeJson
} = require('safe-json-extract');

---

# Module 1

extractJson()

Purpose:

Extract the first valid JSON object found inside arbitrary text.

Input:

Hello

{
"name":"Eliezer"
}

Thanks

Output:

{
"name":"Eliezer"
}

---

# Module 2

extractArray()

Purpose:

Extract the first valid JSON array found inside arbitrary text.

Input:

Result:

[
1,
2,
3
]

Output:

[
1,
2,
3
]

---

# Module 3

safeParse()

Purpose:

Parse JSON without throwing exceptions.

Success:

{
ok: true,
data: ...
}

Failure:

{
ok: false,
error: ...
}

---

# Module 4

isJson()

Purpose:

Quick JSON validation.

Returns:

true

or

false

---

# Module 5

repairJson()

Purpose:

Repair common JSON mistakes produced by LLMs.

Supported repairs:

* single quotes
* trailing commas
* invalid spacing
* malformed line breaks
* accidental markdown wrapping

Example:

{name:'John'}

Becomes:

{
"name":"John"
}

---

# Module 6

extractCodeBlock()

Purpose:

Extract fenced Markdown code blocks.

Input:

```json
{
  "x": 1
}
```

Output:

{
language: "json",
content: "{\n"x":1\n}"
}

---

# Module 7

normalizeJson()

Purpose:

Normalize JSON structures.

Examples:

Name -> name

EMAIL -> email

UserName -> username

Produces consistent keys.

# Security Philosophy

The library must:

* never execute code
* never use eval
* never create functions dynamically
* never perform network operations
* never access files automatically

The library only processes strings.

# v1.1 Roadmap

> **Historical document (archived).**
> This was the planning document for v1.1.0, which has shipped.
> For what actually landed, see the [CHANGELOG](../../CHANGELOG.md#110---2026-06-25).

## Goal

Make safe-json-extract resilient to real-world LLM output.

## Improvements planned

1. **JSON inside markdown blocks**
   - multiple ` ```json ` blocks
   - nested code blocks
2. **Truncated JSON recovery**
   - incomplete objects
   - missing closing braces
3. **Multi-JSON extraction**
   - arrays of objects in text
   - multiple responses in one string
4. **Heuristic repair engine**
   - better quote detection
   - key normalization improvements
5. **Streaming support (future)**
   - handle partial tokens from LLM streams

## Philosophy

Keep:

- zero dependencies

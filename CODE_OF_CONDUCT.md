# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and harassment-free experience for everyone.

## Expected Behavior

* Be respectful
* Be constructive
* Welcome new contributors
* Focus on technical discussions

## Unacceptable Behavior

* Harassment
* Discrimination
* Personal attacks
* Spam or abusive behavior

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that violate this Code of Conduct.
